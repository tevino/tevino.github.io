## 什么是 details 元素

> HTML <details> 元素可创建一个组件，仅在被切换成展开状态时，它才会显示内含的信息。<summary> 元素可为该部件提供概要或者标签。

[detail]: https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/details?utm_source={{ site.utm_source }}

### 演示

<details><summary>演示</summary>

这里是 **Markdown** 内容。

</details>

### markdown
```markdown
<details>
<summary>演示</summary>

这里是 **Markdown** 内容。

</details>
```

## 如何使用

1. 按照[说明][1]切换到 `CommonMarkGhPages`
2. 确保在 `_config.yml` 文件中的 `commonmark.options` 选项中包含 `UNSAFE`
3. 享受这种简洁的用法

[1]: https://github.com/github/jekyll-commonmark-ghpages?utm_source={{ site.utm_source }}#installation

我的配置：

```yaml
commonmark:
  options: ["UNSAFE", "SMART", "FOOTNOTES"]
  extensions: ["strikethrough", "autolink", "table"]
```
